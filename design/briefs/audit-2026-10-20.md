### A5. Issue ledger (root cause → minimal fix)

1. **Hydration #418**  
   Impact High / Effort Low.  
   Cause: `useState(() => typeof window !== "undefined" ? readStored… : DEFAULT)` (`VolumeControl.tsx:82-86`).  
   Fix: always initialize to defaults; read storage in `useEffect`.

2. **Route JS shared with home video stack**  
   Impact High / Effort Medium.  
   Cause: layout-level Mux warmup + hls vendor script (`BootScripts`, `layout.tsx` mux warm).  
   Fix: load hls only when a Mux card mounts or when Work tab is shown.

3. **Geist on every page**  
   Impact Medium / Effort Medium.  
   Cause: `Geist` / `Geist_Mono` on root `className` (`layout.tsx:33-34`, `:136`).  
   Fix: move font providers into embed layouts only.

4. **Silk under reduced motion**  
   Impact Medium / Effort Low.  
   Cause: intentional ambient loop (`PS3Silk.tsx:190-196`).  
   Fix: if policy should match WCAG intent, `stopLoop()` when reduced and draw one static frame.

5. **Nav morph ignores keyboard**  
   Impact Medium / Effort Low.  
   Cause: `morphOn` from hover/tap only (`HalftoneNavLink.tsx:80-81`).  
   Fix: `onFocus`/`onBlur` with `matchMedia("(focus-visible)")` or `:focus-visible` poly via state.

6. **Soft-nav frame drops**  
   Impact Medium / Effort Medium.  
   Cause: Archive gallery hydrate + Mux wake overlapping morph + cursor.  
   Fix: already partially deferred; finish moving Sanity/gallery off the click frame (idle after paint).

### C3. Type scale audit and recommendation

Current tokens (`globals.css:84-119`): hero clamp 32 to 48 / h2 30 / h3 20 / body 15 / label 16 / meta 14 / caption 12 / card title 18 / stat 44. Tracking tokens exist (`--ls-tight` −0.5px through `--ls-wider` 0.08em) but body/nav often use `normal`.

Versus strong references (Josh Puckett / Rauno / Emil): fewer sizes, tighter large display, slightly open small UI, never heavy weights for chrome.

**Recommended scale (cap weight at 500):**

| Step | Size | Weight | Line height | Tracking | Use |
|------|------|--------|-------------|----------|-----|
| Display | clamp(32px, 5vw, 48px) | 400 to 500 | 1.05 to 1.15 | −0.02em to −0.03em (~−0.6 to −1.0px at 40px) | CS heroes |
| Home serif | clamp(26px, 2.8vw, 36px) | 400 | 1.2 | −0.5px (keep) | Home/about titles |
| Title | 22 to 24px | 500 | 1.25 | −0.015em | Section titles |
| H2 | 28 to 30px | 500 | 1.15 | −0.02em | Keep `--fs-h2` / `--ls-h2` |
| H3 | 18 to 20px | 500 | 1.3 | −0.01em | |
| Body | 15px | 400 | 1.65 to 1.72 | 0 to +0.005em (keep 0.1px on CS prose) | |
| Nav / footer | 15 to 16px | 400 | 24px | 0 to +0.01em | Prefer slightly open if SVG optical size feels tight |
| Meta | 13 to 14px | 500 labels / 400 values | 1.4 | +0.01em on labels only | |
| Caption | 12px | 400 | 1.45 to 1.6 | +0.02em | Archive can stay lowercase if intentional |
| Micro | 11px | 400 | 1.3 | +0.02em | Bento captions |

Legibility: keep `--color-text-muted` / tertiary at the darkened WCAG values already in tokens. Avoid tracking on Georgia body-sized text. Do not introduce weights above 500 for site chrome.

### D2. Code races and cleanup

**Solid:**

- `pendingNavSettleRef` + `ignoreHoverUntilRef` prevent leave→enter double morph (`:68-72`, `:149-175`, `:182-188`).
- `animate(...).stop()` on morph progress change (`OutlineMorphWord.tsx:66-70`).
- `loadOutlineMorph` singleton (`outlineMorphLoader.ts:6-11`).
- Coarse pointer never sets hover (`canHover`, `:27-28`).

**Residual risks:**

1. Keyboard never sets `morphOn` (a11y parity).  
2. `WORDS.get(label.toLowerCase())` fallback in `OutlineMorphWord.tsx:58` only helps if lowercase keys remain; `RestingOutlineWord` case-insensitive find is safer. Duplicate Title Case + lowercase datasets (`outlineMorphData.ts` labels at lines 17, 94, 193 and 282, 354, 447) increase payload.  
3. `touchNavRef` timeout not cleared on unmount (`HalftoneNavLink.tsx:279-281`).  
4. Theme/volume controls still on HalftoneDotField; different timing knobs than outline morph (`showDurationMs` 220 vs `OUTLINE_MORPH_S` 0.32s).  
5. DialKit `keepEffectOn` can pin morph forever in dev only (not prod).

**Minimal follow-ups:** focus-visible morph; delete obsolete lowercase outline entries after bake confidence; clear the ghost-click timeout on unmount.
