### Spec: `BentoMinimap` (simplest version)
- **Placement:** bottom-right, `right: var(--page-px)` (24px), with the same bottom as `.bento-zoom-panel` (40px) so it aligns with the zoom slider. Rendered inside BentoGallery's root, `position:absolute; z-index:60`.
- **Size:** 132px wide; height = 132 × canvasH/canvasW, capped at 120px (if the canvas is taller, cap the height and let the width shrink). That makes it about 60% of Carolyn's 220px, which fits the restraint of the rest of the site.
- **Style tokens:** reuse `panelBase` (radius 6 → `--radius-mosaic`, blur 8, same bg/border/shadow) with 6px padding, so it reads as a sibling of the zoom panel. Tiles are `<rect>` with `fill: var(--color-placeholder)` (#EBEBEB) and no stroke, or as an alternative `stroke: var(--color-text-primary)` at 0.75px, opacity 0.35. Use rx 1. The viewport rect is `stroke: var(--color-accent)` (#9590C2) at 1px with `fill: var(--color-accent-subtle)`. That accent replaces Carolyn's green, so there's no new color. A focused tile gets fill `var(--color-accent)` at 0.5. In dark mode, use the same `isDark` switches the panel already uses.
- **Data:** tiles come from `positions[i]` plus the same width/height math the component already has (`colSpan`, `itemImageHeight`), scaled by k = mapW/canvasW. The viewport is `{ x: -tx.x/s, y: -tx.y/s, w: vw/s, h: vh/s } × k`, clamped to the map. Update it imperatively inside `applyTransform` (like `thumbRef`) by setting the rect's attributes through a ref, with no React re-render. During eased transitions, update to the target immediately; that's fine.
- **Interactions, v1 (simplest):** read-only plus click-to-center. On a pointerdown on the map, convert to canvas coordinates and call `applyTransform(vw/2 - cx*s, vh/2 - cy*s, s, "flow")` through the existing `getBounds`/clamp. Stop propagation like the zoom panel does. `aria-hidden`, since keyboard users already have the zoom controls. Fade it in with the gallery's existing enter, and hide it during focus mode or dim it to 0.4.
- **v2 (optional):** drag the viewport rect to scrub (`setPointerCapture`, live `applyTransform(...,"none")`). Optionally auto-hide after 1.5s idle and reveal it on pan.
- **Mobile (<768px):** hidden. At 390 the 4-column bento already fits the width (`overviewMode="width"`), so the only axis is vertical and the zoom slider plus native gesture are enough. If you want something later, use a 3px vertical progress track on the right edge, but skip it for v1.
- **Pannable canvas or vertical-only?** Keep the existing canvas and track the full 2D transform. The overview already fits the width, so at rest the map shows a full-width rect sliding vertically, which looks like a scroll indicator. It turns into a real 2D minimap only when the user zooms in, which is exactly when orientation helps.

**Recommendation:** ship v1: a 132px, desktop-only SVG panel at the bottom-right, in panelBase style with an accent viewport rect, updated from `applyTransform`, with click-to-center. That's about 80 lines in BentoGallery and needs no layout or data changes. Add drag-scrub only if click-to-center feels insufficient.
