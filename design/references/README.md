# design/references

Durable research context for the portfolio. Briefs read this folder **after [TASTE.md](../TASTE.md)**: TASTE wins any conflict, and these files supply the evidence behind it.

| File | What it is | When to read |
|---|---|---|
| [hero-findings.md](hero-findings.md) | Distilled findings from studying the above-the-fold area of 87 portfolios (27 senior and student sites, plus 60 from Open Doors), with counts and the recommended hero structure for Mudit | Any hero, home page, card or about work |
| [portfolio-library.md](portfolio-library.md) | One line per portfolio: link, student or senior, the one thing worth stealing, pattern tags | Looking for a reference for a specific pattern |
| [career-facts.md](career-facts.md) | The only facts copy may state about Mudit. Anything marked TODO is unconfirmed and must not be published | Writing any copy, resume or about text |

Raw screenshots and measurements stay on the box at `/workspace/research/hero/` (not committed): `shots/`, `measure.json`, `measure-od.json`, `contact-sheet.png`, `contact-sheet-2.png`.

Rules: never invent metrics or employers, never call Beacons AI current, and update counts here if the study is re-run.
